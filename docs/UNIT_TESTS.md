# Unit-тестирование микросервисов TravelTech

## 1. Назначение

Unit-тестирование используется для проверки отдельных компонентов микросервисов, в первую очередь бизнес-логики
сервисного слоя.

Тесты позволяют проверить корректность выполнения операций, обработку ошибок и ожидаемое поведение сервисов без
обращения к реальным внешним зависимостям.

Для изоляции тестируемой логики используются mock-объекты (`MagicMock`), заменяющие репозитории и другие зависимости.

Для запуска тестов используется `pytest`.
