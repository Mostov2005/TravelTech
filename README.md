# TravelTech

TravelTech — система управления путешествиями и мониторинга авиарейсов.

## Назначение проекта

Система предназначена для планирования путешествий, управления маршрутами и бронированиями, а также автоматического мониторинга состояния авиарейсов.

При обнаружении отмены или существенной задержки рейса система анализирует влияние изменения на путешествие пользователя, ищет доступные альтернативы и предлагает варианты корректировки маршрута.

## Основные возможности

- Регистрация и авторизация пользователей.
- Создание и управление путешествиями.
- Формирование маршрутов.
- Управление бронированиями.
- Получение информации об авиарейсах и аэропортах.
- Мониторинг статусов авиарейсов.
- Обнаружение отмен и задержек.
- Поиск альтернативных рейсов.
- Корректировка маршрутов.
- Уведомление пользователей.

## Архитектура

Проект разрабатывается на основе Domain-Driven Design (DDD) с использованием микросервисной архитектуры и принципов Clean Architecture.

Предварительно планируется выделить пять ограниченных контекстов, каждый из которых будет реализован отдельным микросервисом.

## Статус разработки

Проект находится на этапе проектирования предметной области и архитектуры.
